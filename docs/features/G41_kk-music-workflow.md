# G41: kk-music workflow

## Goal

Home child for the `kk-music` product workflow (`plugins/kk/workflows/kk-music.yaml`), the workflow-tree
counterpart of feature D8's music capability. G's invariant is that every product workflow in that
directory is homed by exactly one G child; D8 owns the capability (plugin, presets, spend guard, audio
engineering, CLI noun, skill, rubric), and this child owns the workflow's place in the tree.

The workflow itself — prepare → brief → explore → select → analyze → check → judge → master →
finalize, one paid take per differentiated brief in the format's own model, `select` as the only
operator gate, measurement before judgement and delivery check before finalize — is specified and
delivered by D8 task 0403. Nothing here re-specifies it; this child exists so the tree's
one-home-per-workflow rule keeps holding as product workflows are added.

## Scope

- In: the `kk-music` workflow's home in the G collection — its identity in the workflow tree, and the
  pointer from the tree to the capability that specifies it (feature D8).
- Out: the workflow's behaviour and its states (D8 task 0403), the music plugin and its adapters
  (D8 0397-0400), the audio engineering (0405), the CLI noun (0401), the skill and rubric (0402), and
  any publish channel for music (deferred, see D8 Notes).
