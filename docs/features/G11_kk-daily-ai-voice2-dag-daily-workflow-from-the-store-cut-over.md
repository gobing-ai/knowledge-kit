# G11: kk-daily-ai-voice2: DAG daily workflow from the store, cut-over

## Goal

Rebuild the daily AI-news episode pipeline as `plugins/kk/workflows/kk-daily-ai-voice2.yaml`, a thin `kind: dag` workflow that starts from the kk-collect store pool, runs independent branches concurrently with plugin-owned `kk` steps, and replaces `kk-daily-ai-voice.yaml` after a measured parity streak.

## Scope

- In: voice2 DAG (one action per node, file-passing), nested `kk-daily-safety.yaml` state-machine for the review/judge/revise loop, operator review as a pause node, moving touched stage logic out of `kk-workflow-stages.ts` into plugins / `kk` subcommands, `kk ledger cutover-check`, end-to-end dogfood, ADR-031.
- Out: store, collection and labeling (G31); ledger rendering (G71); retiring the old YAML (follow-up after cut-over); TTS/voice driver or publish channel changes.
