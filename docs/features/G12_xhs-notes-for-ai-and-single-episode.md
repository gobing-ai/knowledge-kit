# G12: XHS notes for 每日AI乱炖: 上传图文 and single-episode 发播客

## Goal

Give each 每日AI乱炖 episode two Xiaohongshu creator notes: an 上传图文 note that spends that episode's generated images with matching text, and a 发播客 note that uploads that episode's mp3 and cover as one episode. The creator console does not offer a usable RSS import, so the podcast note is a single-episode upload. This is important and not urgent.

## Scope

- In: the voice2 上传图文 note (which images, in what order, with what text) and the image-generation change only where a current image cannot serve that pairing; the voice2 发播客 note (上传音频, that episode's mp3, that episode's cover, the form fields the console requires); draft save through `xhs-pub` for both operations; the fact that creator drafts live in the XHS browser profile.
- Out: RSS import; turning `xhs_live` on; WeChat, Surfdash, and the podcast site; restoring the draft box the operator emptied on 2026-10-09; `kk-daily-ai-voice.yaml`; a second card-text renderer beside F616.
