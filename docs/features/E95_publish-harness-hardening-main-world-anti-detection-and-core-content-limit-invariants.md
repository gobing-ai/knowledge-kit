# E95: Publish harness hardening: MAIN-world anti-detection and core content limit invariants

## Goal

Harden `@gobing-ai/publish-harness/browser` and `@gobing-ai/kk-core` with opt-in browser automation helpers and content limit invariants learned from the 一键发 Chrome extension: MAIN-world anti-detection / file-dialog suppression hooks, and a centralized content limits & deterministic thread-splitting engine.

## Scope

- In:
  - `@gobing-ai/publish-harness/browser`: export `injectBrowserAntiDetection(page: Page, options?: AntiDetectionOptions)` using Playwright `page.addInitScript`.
  - Xiaohongshu shield interceptor: intercepts `/shield/webprofile` via `fetch`, `XHR`, `sendBeacon`, spoofing `{ code: 0, success: true, msg: "ok", data: { st: Date.now() } }` with `makeNativeLike` disguised functions.
  - File dialog suppression hook: hooks `document.createElement("input")` in MAIN world to capture `type="file"`, suppresses native OS file picker modals on `input.click()` when pending files exist, and populates `el.files` directly via `DataTransfer`.
  - `@gobing-ai/kk-core`: new module `content-limits.ts` with `PlatformContentLimits` schema, per-platform title/body caps, and counting algorithms (`utf16_code_units`, `unicode_code_points`, `weighted` CJK/ASCII, Twitter 23-char URLs).
  - `@gobing-ai/kk-core`: new module `thread-segmentation.ts` implementing URL-preserving, invariant-checked text splitting for Threads and X (reconstructed thread segments strictly equal original input text).
  - Single-file unit test suites in `publish-harness` and `kk-core` with >=90% line and function coverage.
- Out:
  - Modifying existing channel business logic (existing channels opt into these shared utilities).
  - Remote cloud CAPTCHA solving services.

    Given text content evaluated under `PlatformContentLimits`

    Given an input body exceeding single-post platform limits
    When `splitThreadContent` decomposes the text into a thread sequence
    Then URLs are never split across post boundaries
    And the concatenated post sequence strictly equals the original input text
