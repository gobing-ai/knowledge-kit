# G82: Daily AI Voice module Summary: real channel yield and episode funnel

## Goal

Make the Daily AI Voice Board module's **Summary** tab answer two operator questions with store and artifact facts instead of run-status only: **what did this episode consume** (which source channels delivered, which ingestion plugin went dark) and **why did today produce nothing** (pool → kept → planned → measured minutes against the episode floor).

## Scope

**In scope**

- Two read-only yield tables on the Summary tab, scoped to the selected run's collection window: new items per local day per `items.source`, and per-ingestion-plugin counts from `collect_runs.source_counts_json` with the tick count.
- An episode funnel fed by the run's own artifacts: extract pool → kept after QC filter, topic-boundary and title dedup (with the exclusion rules) → planned items → estimated vs measured minutes against `episode_min_minutes`–`episode_max_minutes`.
- A `no-content` outcome line naming the gate that closed the run (script pre-spend refusal, measured duration refusal, or empty pool) with its recorded numbers and the refusal-artifact path.
- Explicit unknowns: a missing artifact or unavailable store renders an unknown marker, never `0`; no ratio over a zero denominator.
- Same-commit surface docs (`docs/04_DESIGN.md`, `docs/design/workflow-board-modules.md`) and a browser verification artifact against the real 2026-10-22 / 2026-10-21 runs.

**Out of scope**

- Any store write, relabelling, selection editing or execution control (start/retry/cancel) from the Board.
- Changing the extract/plan/QC/generate stages or the store schema; this task reads what they already write.
- Store-backed panels outside Summary, and any view for the IT Content module.
- Time-range pills on this tab: the window is derived from the selected run, not chosen globally.
