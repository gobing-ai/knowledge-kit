# G13: Segmented episode speech for daily voice2

## Goal

Give each 每日AI乱炖 episode its speech as an opening, one section per selected item, and a closing, then one joined file with the existing intro sting, so a failed or rewritten section is the only part synthesized again. The joined episode still lands in the 15–20 minute window.

## Scope

- In: group the voice2 spoken script into an opening, one section per selected item, and a closing.
- In: synthesize each section to its own audio file and keep a finished section when its text is unchanged.
- In: on a retry, synthesize only sections whose audio is missing or whose text no longer matches.
- In: join the section speech in order, then apply the existing intro sting, and leave one episode file for the duration check and publish preparation.
- In: a concurrency count whose everyday value is 1.
- In: when the joined episode is too long, synthesize again only the sections whose text changed.
- In: when the provider refuses the account for this window, stop and keep the sections already finished.
- In: keep the 15–20 minute window and the current spoken-length and item-count caps.
- Out: raising the episode length window, the spoken-length caps, or the item cap.
- Out: changing the shared script builder so voice1 speech changes.
- Out: editing `kk-daily-ai-voice.yaml`.
- Out: synthesizing more than one section at a time in this delivery.
- Out: treating the intro sting as a spoken section.
- Out: web fact-checking, and the Xiaohongshu notes already filed under G12.
