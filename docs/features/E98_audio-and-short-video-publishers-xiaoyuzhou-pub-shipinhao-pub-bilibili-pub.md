# E98: Audio and short-video publishers: xiaoyuzhou-pub, shipinhao-pub, bilibili-pub

## Goal

Connect knowledge-kit multimedia generation pipelines (`omni-voice-gen`, `podcast-pub`, `video-gen`) to major domestic podcast and short-video distribution channels by creating `xiaoyuzhou-pub` (小宇宙), `shipinhao-pub` (微信视频号), and `bilibili-pub` (B站).

## Scope

- In:
  - `plugins/publishings/xiaoyuzhou-pub`: operation `podcast` (podcaster.xiaoyuzhoufm.com audio upload, episode title, shownotes markdown, episode cover image).
  - `plugins/publishings/shipinhao-pub`: operation `shortVideo` (channels.weixin.qq.com with `<wujie-app>` shadowRoot traversal, video upload, cover crop, original declaration protocol).
  - `plugins/publishings/bilibili-pub`: operations `shortVideo` (member.bilibili.com video upload, partition selection, tags) and `dynamic` (t.bilibili.com image-text dynamic post).
  - Micro-frontend shadow DOM support and Ant Design component handling in `@gobing-ai/publish-harness/browser`.
  - Integration with `@gobing-ai/publish-harness` with fake transports and session preflight.
  - Dedicated unit tests for each plugin meeting >=90% line and function coverage.
- Out:
  - Long video encoding and transcoder pipelines (handled upstream in generator plugins).

## Acceptance Criteria

```gherkin
Feature: Audio and short-video publishers: xiaoyuzhou-pub, shipinhao-pub, bilibili-pub

  Scenario: R1 - xiaoyuzhou-pub uploads episode audio and shownotes
    Given an authenticated Xiaoyuzhou podcaster session and an audio Content payload
    When `xiaoyuzhou-pub` executes operation `podcast`
    Then audio file is uploaded, cover attached, shownotes rendered, and episode draft saved

  Scenario: R2 - shipinhao-pub traverses shadowRoot and uploads short video
    Given an authenticated Channels session with `<wujie-app>` shadow DOM
    When `shipinhao-pub` executes operation `shortVideo`
    Then video file is uploaded, cover cropped, original declaration checked, and publication state read back

  Scenario: R3 - bilibili-pub handles video and dynamic publishing
    Given an authenticated Bilibili creator session
    When `bilibili-pub` executes operation `shortVideo` or `dynamic`
    Then video/dynamic content is published with verified completion signals
```
