# K1: image-gen preset sample gallery README

## Goal

Give image-gen users a visual index of every shipped format × style preset combination: a plugin
README backed by real sample images, so a user can pick a format and style by eye instead of reading
YAML modifier prose, and maintainers can regenerate the gallery when presets change.

## Scope

**In scope**
- `plugins/generations/image-gen/README.md`: format and style overview tables plus a format × style sample grid covering every shipped pair (5 × 12 = 60 today).
- Sample images generated with real provider calls into `plugins/generations/image-gen/assets/sample/`, one per pair, default template variables.
- A committed, resumable script that enumerates shipped presets, generates missing samples, and rewrites the README, so the gallery is repeatable.
- README names the provider/model that rendered the samples and marks each format's `defaultStyle`.

**Out of scope**
- Editing, adding, or removing any format/style preset.
- User/project preset roots (`~/.config/kk/image-presets`, `KK_IMAGE_PRESET_PATH`) — shipped presets only.
- Per-provider comparison galleries; one provider renders the whole matrix.
- Changes to image-gen runtime code, the `kk` CLI surface, or `docs/04_DESIGN.md` surface tables.
