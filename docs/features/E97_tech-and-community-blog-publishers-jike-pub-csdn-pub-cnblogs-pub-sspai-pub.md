# E97: Tech and community blog publishers: jike-pub, csdn-pub, cnblogs-pub, sspai-pub

## Goal

Extend knowledge-kit written content distribution to top domestic developer and creator communities by creating 4 new `kind: publish` plugins: `jike-pub` (即刻), `csdn-pub`, `cnblogs-pub`, and `sspai-pub` (少数派) built on `@gobing-ai/publish-harness`.

## Scope

- In:
  - `plugins/publishings/jike-pub`: operation `post` (web.okjike.com dynamic post, topic tag auto-completion, multi-image upload).
  - `plugins/publishings/csdn-pub`: operation `article` (mp.csdn.net markdown editor, title/tags, cover upload, draft/publish).
  - `plugins/publishings/cnblogs-pub`: operation `article` (i.cnblogs.com markdown editor, category selection, draft/publish).
  - `plugins/publishings/sspai-pub`: operation `article` (sspai.com creator editor, markdown paste, cover upload).
  - Each plugin implements `driver: "script"`, `profile-check.ts` for login readiness probe, observed signal success verification, and fake transports.
  - Dedicated unit tests for each plugin meeting >=90% line and function coverage.
- Out:
  - Bypassing platform SMS/captcha verification during manual login.
