# F4: IT-content workflow and product YAML home

## Goal
Make `plugins/kk/workflows/` the only home for knowledge-kit product workflow YAML, and ship a `kk-itc` state machine that authors an IT technical draft using existing Spur HITL (`hitl.select` / `hitl.confirm` / `hitl.input`) plus `agent.run` — no new `hitl.*` kind and no dedicated HITL skill.
## Scope
- In: relocate kk product YAML (`kk-storm-research`, `kk-ingest-generate-publish`, `judge-gated-publish-example`) so `plugins/kk/workflows/` is the repo SSOT; drop the `.spur/workflows/` copies; shrink the 0056 copy rule to `KK_WORKFLOWS_SOURCE` then `plugins/kk/workflows`; author `plugins/kk/workflows/kk-itc.yaml` using existing `hitl.select` / `hitl.confirm` / `hitl.input` plus `agent.run` (`topic` / `itc-generating` as writers, `content-judge` as the quality gate); update `/workflow-run`, tests, and help to the new SSOT.
- Out: a new Spur `hitl.*` action kind; deleting or renaming the `topic` skill in this pass (`topic` stays the standalone writer; HITL gates move to the workflow); a new `kk` first-layer noun (ADR-011); live publish; image generation; changing the `content-judge` verdict contract.
