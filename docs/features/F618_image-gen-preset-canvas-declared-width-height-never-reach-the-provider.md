# F618: XHS daily card target with automation-risk guard (ADR-025)

## Goal

**A preset that declares a canvas must deliver it.** The `xhs-card` format declares
`width: 1080 / height: 1440`, but `image-gen` builds the provider request with only
`aspectRatio: format.aspectRatio` (`src/index.ts`), never forwarding the dimensions. MiniMax
therefore returned its own 3:4 size — measured **864x1152**, about 30% smaller per axis than
declared. Every format preset's canvas is currently decorative, which both lies about the output
contract and works against text legibility.

## Scope

**In scope**

- Forwarding declared dimensions to providers whose API accepts them, and recording the delivered
  artifact size in the artifact metadata for providers that accept only an aspect ratio.
- Making the declaration honest where a provider cannot honour it.
- A regression assertion pinning the measured 864x1152 case.

**Out of scope**

- The XHS card composer and its safe-area/typography rules — filed as F616.

## Acceptance Criteria

```gherkin
Feature: image-gen canvas declarations are delivered, not decorative

  @core
  Scenario: R1 — A declared preset canvas reaches the provider
    Given a format preset declaring width 1080 and height 1440
    When image-gen builds the provider request for a provider that accepts explicit size
    Then the request carries the declared dimensions
    And the emitted artifact is exactly that size

  @core
  Scenario: R2 — A provider that cannot honour the canvas is honest about it
    Given a provider whose API accepts only an aspect ratio
    When image-gen builds the request
    Then the delivered artifact size is recorded in the artifact metadata
    And a preset cannot claim a canvas the provider will not deliver

  @edge
  Scenario: R3 — The measured regression stays fixed
    Given the xhs-card preset at 3:4 on MiniMax image-01
    When image-gen requests the raw provider image
    Then the request carries 1080x1440 rather than the aspect ratio that produced 864x1152
    And the delivered size is recorded, so a regression is visible in the metadata
```

> Scope note (2026-09-29 refinement): R3 pins the **raw provider artifact**. The composed XHS card's 1080x1440 canvas
> is owned by F616 (task 0180) and holds regardless of provider.
