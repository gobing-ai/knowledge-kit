# E96: WeChat MP publisher modernization: same-origin CGI draft and media pipeline

## Goal

Modernize plugins/publishings/wechatmp-pub with authenticated-browser same-origin CGI media preparation and creation for eligible plain article drafts. Preserve existing advanced article settings, other modes, session preflight and public DOM rails. Latency improvement remains to be measured; no <3s guarantee or elimination of all races is established.

## Scope

- In:
  - `plugins/publishings/wechatmp-pub`: refactor eligible plain-article draft dispatch in `runMode`; extract transient `token`, `ticket`, `user_name` and optional `uin` from bounded known page fields, preserving advanced metadata and all other mode/public DOM flows.
  - Cover upload and auto-crop: `POST /cgi-bin/filetransfer?action=upload_material` (scene=8) followed by `POST /cgi-bin/cropimage?action=crop_multi` for 2.35:1 (head) and 1:1 (feed) crops.
  - In-body image CDN upload: parse HTML, extract `<img src>`, call `POST /cgi-bin/uploadimg2cdn`, and replace local/remote URLs with WeChat CDN URLs.
  - Link sanitization: automatically convert `<a href="...">text</a>` into `<span>text</span>` as this publisher's conservative external-link normalization, without claiming a universal platform prohibition.
  - Draft creation: call `POST /cgi-bin/operate_appmsg?t=ajax-response&sub=create&type=77` and verify `appMsgId`.
  - Preserve existing `wechatmp-pub` CLI interface, `publishStatus` draft/public rail, and `FakeFileCliTransport` testing support.
  - Single-file unit test suite passing >=90% line and function coverage.
- Out:
  - Automatic live mass-send without human verification (WeChat policy mandates mobile QR code confirmation for live publishing; draft creation remains the automated terminus).
