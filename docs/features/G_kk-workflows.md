# G: kk workflows

## Goal

Collection parent for kk product workflows (`plugins/kk/workflows/*.yaml`) and the workflow infrastructure they share. One child per workflow (G1 kk-daily-ai-voice, G2 kk-itc, G3 kk-collect, G4 kk-solo-podcast, G5 kk-storm-research, G6 kk-ingest-generate-publish); cross-workflow capabilities (run ledger) get their own child (G7). Mirrors the kind-parent pattern of C/D/E/F.

## Scope

- In: workflow YAML under `plugins/kk/workflows/`, the `kk` steps a workflow owns end-to-end, workflow-shared infrastructure (store, ledger, schedules); one child per workflow, grandchildren per change.
- Out: plugin instances (C/D/E), `plugins/kk` agent capabilities (F), engine/runtime work in ts-libs or spur, example workflows (`*-example.yaml`).

## Acceptance Criteria

