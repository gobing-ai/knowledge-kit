# B2: Typed lifecycle contracts

## Goal
TypeScript interfaces for IngestionPlugin, ContentGeneratorPlugin, and PublishPlugin, with their lifecycle methods and shared Doc / Content / Result types.
## Scope
- In: `@gobing-ai/kk-core` Zod schemas for Doc / Content / Result; per-kind input/output contract resolution; inferred TS type exports.
- Out: transport, discovery (B1), and invocation (B3); persistence of payloads beyond file/JSON exchange.
## Acceptance Criteria
