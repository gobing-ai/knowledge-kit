# F9: Explain-things skill and tell-me command

## Goal
Ship one fat agent skill that explains a topic with the smallest useful view, plus a thin `/tell-me` slash wrapper, harvested from vendor `eli5` and `show-me` without becoming a `kk` CLI verb or a runtime plugin.
## Scope
- In: fat skill `plugins/kk/skills/explain-things/` (`name: explain-things`); distilled `references/views.md` (show-me view catalog, one level deep); smallest-view default with ELI5 register on request and HTML last-resort; empty args use the current conversation topic else fail loud; thin slash command `plugins/kk/commands/tell-me.md` that delegates to the skill; Superskill validate + `superskill install kk --dry-run`; README / DESIGN surface note for the new capability.
- Out: extra `/eli5` or `/show-me` alias commands; persona subagent under `plugins/kk/agents/`; new `kk` first-layer noun or verb (ADR-011); generator `plugin.json` / `kk executor run` seam; live HTML app or image generation; copying `vendors/misc/eli5` or `show-me` wholesale into the skill tree; workflow YAML; changes to `topic`, `itc-generating`, `storm-research`, or `content-judge`.
