# D: ContentGeneratorPlugin

## Goal
Content generation = the platform's creation capability, co-equal with ingestion: a ContentGeneratorPlugin takes `Doc[] | Brief` and produces Content (ADR-007 R3). Brief-first creation (topic → article with nothing ingested) is a first-class pipeline, not a special case. Roll-up parent: generator design (D3, done) and instances — the D1-chosen stand-in skill (D2). Own STORM (D4) and wt generator harvest (D5) deferred to Phase 3.
## Scope
- In: STORM study / stand-in pick (D1, done); wire stand-in generator (D2); generator plugin design (D3, done); Brief input contract (`Doc[] | Brief`, task 0032 design); own STORM (D4, Phase-3 deferred); wt generator harvest (D5, Phase-3 deferred).
- Out: publish targets; ingestion; audio/other formats this phase.
