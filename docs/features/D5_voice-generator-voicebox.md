# D5: Voice generator (Voicebox)

## Goal
Turn a text or VoiceScript brief into generated speech audio through a kind=generator plugin that drives the local Voicebox REST `/generate` API.
## Scope
- In:
  - `plugins/generations/voice-gen` (`kind: generator`) discoverable by the existing registry
  - D3 invoke contract: `Doc[]` `--in` → `Content` `--out`; fail-loud exit codes; empty Doc[] notice
  - kk-owned VoiceScript (YAML or JSON) as the multi-speaker input format — Voicebox has no document script schema
  - Plain `Doc.body` as a single-speaker shortcut using a default Voicebox profile
  - REST transport to `POST {VOICEBOX_URL}/generate` (default `http://127.0.0.1:17493`), poll status, copy `GET /audio/{id}` into the workspace
  - Length policy: fail-loud if any segment exceeds 50,000 characters; pass Voicebox auto-chunk knobs through; do not use `POST /speak` (10k cap)
  - `Content` mapping: `format: "audio"`, `body` = canonical VoiceScript or transcript, `metadata.audioPath` / `duration` / `segments[]` — no kk-core schema change
  - Offline unit tests with a fake Voicebox HTTP server (no live GPU)
- Out:
  - Podcast spur workflow (research → script → voice → publish) — follow-on
  - MCP `voicebox.speak` as plugin transport; `POST /speak`; Voicebox Stories as the input format
  - Patching or importing `vendors/voicebox`; cloning voices; STT / transcribe
  - New plugin kind; binary `Content.body`; Zod schema change
  - Audio publish channels; personality rewrite; effects-chain authoring UI
